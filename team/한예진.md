# 한예진 자기소개

## 한 줄 소개

사람들의 페인포인트를 발견하면 분석하고 기록한 뒤 직접 실행해 보는 한예진입니다.

## 관심 분야

- 사람들의 불편을 해결하는 서비스 기획과 창업
- 사용자의 취향과 목적을 반영하는 AI 기반 초개인화 서비스

## 요즘 배우는 것

- Spring 기반 백엔드 개발과 AI를 협업 파트너로 활용하는 방법
- 코드 리뷰, 문서화, 지식 관리를 통해 팀이 더 명확하고 효율적으로 일하는 방식

## 팀원들에게 보여주고 싶은 모습

문제를 발견하면 그냥 지나치지 않고 작은 실행으로 검증하는 팀원이 되고 싶습니다. 필요한 환경이 없을 때도 기다리기보다 직접 만들고, 맡은 일은 끝까지 책임지겠습니다. 서로의 생각을 나누며 혼자서는 만들기 어려운 결과를 함께 만들어가고 싶습니다.
