# Team 5 이어서 작업하기

2026-09-10 기준으로 밝은 경기장의 팩 선택부터 팀원 카드 공개, 전체 모음, 상세 소개까지 구현했습니다. 개인 정보와 발표용 캐릭터의 최종 확인은 아래 남은 항목을 참고합니다.

## 요청과 결정 요약

1. 팀원 세 명을 FIFA 카드 뽑기 같은 게임 화면으로 소개합니다. 플랫폼형 메뉴와 별도 서비스 기능은 넣지 않습니다.
2. 시안을 먼저 검토하고 밝은 경기장, 은색과 아이보리 팩을 기준으로 정했습니다. 공개 중에만 조명이 낮아집니다.
3. 팩에는 이름, 이니셜, 캐릭터를 표시하지 않습니다. 선택할 때 남은 팀원 중 무작위로 한 명을 뽑고, 한 회차에 중복되지 않습니다.
4. 학교 로고 → 학과 → 등장 키워드를 한 화면에 하나씩 보여준 뒤 카드를 공개합니다. 예진님은 코코네스쿨 → 소프트웨어전공 → 범고래입니다.
5. KAI와 MBTI는 공통 항목으로, 능력은 개인별 태그로 표현합니다. 축구 능력치 여섯 개와 임의의 점수는 사용하지 않습니다.
6. 발표자가 다음 팩을 선택합니다. 세 명이 모두 공개되면 밝은 화면에서 카드 세 장을 보여주고, 클릭하면 상세 소개를 엽니다.
7. 이전 세션은 홈페이지 반영 요청 직후 중단됐습니다. 이후 요청에 따라 구현을 이어서 진행했습니다.

## 실행과 검사

```bash
python3 -m http.server 8000
```

`http://localhost:8000`에 접속합니다. md를 읽어야 하므로 파일을 더블클릭하는 방식은 지원하지 않습니다. 별도 빌드와 패키지 설치는 없습니다.

```bash
node --check script.js
node --test tests/profiles.test.mjs
git diff --check
```

Node.js 20 이상을 사용합니다. 테스트는 md 값, 힌트 순서, 빈 항목 처리, 기존 제목 형식 호환, 중복 없는 뽑기를 확인합니다.

## 수정할 파일

| 파일 | 역할 |
| --- | --- |
| [index.html](../index.html) | 선택, 개봉, 힌트, 공개, 모음 화면과 카드 틀 |
| [styles.css](../styles.css) | 경기장 조명, 개봉 효과, 카드 스타일, 화면 크기 대응 |
| [script.js](../script.js) | 화면 전환, md 읽기, 상세 소개, 재시작 |
| [profiles.mjs](../profiles.mjs) | md 파싱, 빈 힌트 생략, 무작위 뽑기 |
| [팀원 템플릿](../team/TEMPLATE.md) | 카드 정보와 등장 힌트 작성 형식 |
| [자산 출처](../assets/game/SOURCES.md) | 경기장, 팩, 범고래, 학교 로고 출처 |

각 팀원은 `team/<이름>.md`의 프로필 카드와 등장 힌트를 수정합니다. 이미지 경로는 저장소 루트 기준입니다. 자기소개 본문은 기존 `##` 형식과 템플릿의 `###` 형식을 모두 읽습니다. HTML은 실행하지 않고 텍스트로 표시합니다.

## 아직 확인할 내용

- 엄태웅님과 김영광님의 학과는 원문에 없습니다. 현재 빈 값으로 두고 해당 힌트를 생략합니다.
- 엄태웅님의 상세 자기소개는 아직 템플릿 상태입니다. 상세 화면에는 준비 중이라는 안내만 표시합니다.
- 웃는 쿼카와 `#웃음`은 시안용 후보입니다. 태웅님 확인 후 이미지와 태그를 md에서 바꿀 수 있습니다.
- 강아지와 쿼카 캐릭터 후보, 화면 시안은 각각 `assets/character-candidates/`, `assets/design-candidates/`에 있습니다. 시안에 포함된 글자는 실행 데이터가 아니며 md 값이 우선합니다.
- 메인 화면 관련 팀 의견은 [이슈 #8](https://github.com/beyejin/team5-study-mate/issues/8), [이슈 #11](https://github.com/beyejin/team5-study-mate/issues/11)에 남아 있습니다. 이번 구현은 이후 인터뷰에서 정한 밝은 팩 선택 흐름을 따릅니다.
