02 / ROADMAP

과제는 이렇게 정리하고 있습니다.

  1. 01
    자기소개 작성

    각자 템플릿으로 공개할 소개를 작성합니다.

  2. 02
    브랜치와 PR 검토

    바뀐 내용은 함께 확인하고 안전하게 합칩니다.

  3. 03
    README와 웹 반영

    팀원이 쓴 내용은 저장소와 홈페이지에서 함께 볼 수 있습니다.

  4. 04
    과제 결과물 준비

    남은 작업은 마일스톤 기준으로 보드에서 관리합니다.

03 / GIT

Git으로 각자 작업한 내용을 모으고, 같이 확인합니다.

clone → branch → edit → status/diff → commit → push → Pull Request

Branch
각자 intro/<이름>에서 작업해 충돌을 줄입니다.
Check
git status와 git diff로 바뀐 내용을 먼저 확인합니다.
Review
팀원이 확인하면 main에 반영하고 최신 내용을 받습니다.
